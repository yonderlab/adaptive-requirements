Add Vue 3 integration at `@kotaio/adaptive-form/vue` with Composition API components, `v-model` binding, scoped slots for field and step-navigation overrides, multi-step flows, async validation, and parity with the React entrypoint.

React and Vue are optional peer dependencies — install only the framework you use (`react` + `react-dom`, or `vue`). This avoids irrelevant missing-peer warnings when consuming a single framework entrypoint.
